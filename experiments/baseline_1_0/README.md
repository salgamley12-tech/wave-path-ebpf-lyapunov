# Baseline 1.0 Experimental Boundary

This directory contains controlled experiments performed after
the Wave Path 2.0 Baseline 1.0.

The baseline remains unchanged.

Each experiment must define:

1. Initial state
2. Controlled change
3. Observable outputs
4. Measurement method
5. Reproducible execution
6. Result
7. Limitations

Experimental results must not be modified to match the reference layer.
