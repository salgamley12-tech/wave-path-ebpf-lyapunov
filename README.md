# AQI Sovereign Kernel
A Rust-based eBPF/XDP sovereign security kernel designed for deterministic data filtering and stability control.

## Project Structure
- `src/`: Core eBPF/XDP packet filtering and kernel modules.
- `Makefile`: Build, compilation, and automation configurations.

## Architecture & Goals
- Implements low-level network packet filtering using eBPF/XDP mechanisms.
- Focuses on determinism, memory safety via Rust, and stability control loops.
