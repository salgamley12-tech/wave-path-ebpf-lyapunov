# Experimental protocol

1. Freeze the textual relation and transformation rule before collecting test results.
2. State the mathematical model and all parameters.
3. Specify observable variables and sampling rate.
4. Generate or collect measurements without tuning the model to the held-out data.
5. Compute prediction error and uncertainty.
6. Compare against a baseline model.
7. Record failures as results, not as implementation mistakes unless independently demonstrated.
8. Repeat across seeds/workloads where relevant.

## Null hypothesis
The proposed text-derived methodological rule does not improve prediction or system behavior beyond an explicitly specified non-textual baseline.

## Key outcome
A claim of scientific novelty requires an independently reproducible result, not semantic similarity between text and an existing equation.
